┌─ CÓMO FUNCIONA ───────────────────────────────────────────────────────────────┐
│                                                                                │
│  1. Usuario hace login                                                        │
│  2. Frontend obtiene rol del AuthService                                      │
│  3. Frontend muestra badge coloreado + sugerencias del rol                   │
│  4. Usuario hace pregunta                                                     │
│  5. Frontend envía: POST /api/ai/inventory-assistant {"question": "..."}     │
│  6. AiController extrae rol automáticamente                                  │
│  7. RoleBasedContextFilter filtra datos según rol                           │
│  8. RoleBasedPromptBuilder obtiene instrucciones del rol                     │
│  9. Construye prompt con contexto filtrado                                   │
│  10. Gemini API responde adaptado al rol                                     │
│  11. Frontend muestra respuesta                                              │
│                                                                                │
│  CLAVE: El filtrado ocurre en backend, no en frontend                       │
│         → No puedes "burlar" los permisos desde frontend                    │
│                                                                                │
